# Push_Swap

## 📝 Description
Push swap is a project that involves sorting of data using two circular stacks and a fixed set of instructions to manipulate the two stacks. The goal is to create a C program that calculates and displays the shortest sequence of Push_swap instructions needed to sort the integer array.

## 🛠️ Instructions
1.  **Clone the Rpository**
    ```bash
    git clone [Repo] [folder_name]
    ```

2.  **Create the program**
    ```bash
    make
    make bonus
    make clean
    ```

3.  **Test the program**
    ```bash
    git clone https://github.com/gemartin99/Push-Swap-Tester
    cp push_swap Push-Swap-Tester/push_swap
    cd Push-Swap-Tester 
    bash push_swap_test_linux.sh
    ```
    
    To visualise the program
    ```bash
    git clone https://github.com/o-reo/push_swap_visualizer.git
    cd push_swap_visualizer
    mkdir build
    cd build
    cmake ..
    make
    ./bin/visualizer
    ```
